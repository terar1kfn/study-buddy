# Study Buddy

Private first-semester dentistry study platform. The home page follows the supplied course dashboard, and course pages use expandable lecture sections. Dental Materials is the first fully developed course shell. Final lab lectures are the priority; unavailable source material is explicitly marked as pending. Gypsum Products is the first source-based interactive lesson (39-page lecture supplied by the user). No other lecture content is invented.

## Run
Open `index.html` in a modern browser, or run `python -m http.server 8000` from the repository and visit `http://localhost:8000`. The first release is a static, dependency-free app; progress and checklist states are stored on the current browser. The original lecture PDF is not uploaded to GitHub in this release; use the source-file selector in the lesson to open your local copy.

## Content policy
Each published lesson must retain important concepts, definitions, quantities, exceptions and source page references. Distinguish conceptual simulations from measured predictions. Keep discrepancies visible. Add lab lessons one at a time after source receipt.
